# Phase 0 spikes (2026-10-20)

Probe script: `spikes/s1_decide_probe.py` (throwaway). Run date: 2026-10-20. All responses below are verbatim from live calls; the `Authorization` header is never recorded and one `user_id` field in an error body is redacted.

## S1: Mercury Decide API

**Verdict:** GO. The endpoint exists, works on both models, accepts images, and the free tier did not rate-limit a 40-way burst. Two shape differences from the research (below): the boolean type is `noul`, and responses carry `legend`/`confidence` extras.

### Endpoint

`POST https://openrouter.ai/api/v1/systemone`

- Headers: `Authorization: Bearer <OPENROUTER_API_KEY>`, `Content-Type: application/json`.
- 404 fallbacks (`/decisions`, `/evaluate`) were not needed.
- Models: `inception/mercury-decide:free` and `inception/mercury-decide` (paid). Both resolve to `"model": "inception/mercury-decide-20260930"` in responses.
- `GET https://openrouter.ai/api/v1/models` does NOT list decision models by default. Use `?output_modalities=all` (or `decisions`). Valid `output_modalities` values per the API: `text, image, embeddings, audio, video, rerank, decisions, speech, transcription, all`.
- Verbatim model-list facts, identical for both ids: `architecture.modality` = `"text+image->decisions"`, `architecture.input_modalities` = `["text","image"]`, `architecture.output_modalities` = `["decisions"]`, `supported_parameters` = `[]`, `context_length` = 65536, `top_provider.max_completion_tokens` = 58982. Pricing: paid `{"prompt":"0.00000002","completion":"0","input_cache_read":"0"}`; free `{"prompt":"0","completion":"0"}`.
- Same API contract is shared by other decision models on OpenRouter (`upstage/solar-decide`, `perplexity/pplx-decider-v1.2`, ...).

### Request (boolean / choice / score)

One request carrying all three question types (this exact body succeeded, HTTP 200):

```json
{
  "model": "inception/mercury-decide:free",
  "state": {
    "ticket": "I was charged twice for my subscription this month and the app keeps crashing."
  },
  "questions": {
    "is_billing_issue": {
      "type": "noul",
      "instructions": "Does the ticket concern a billing problem?"
    },
    "category": {
      "type": "choice",
      "instructions": "Which category best fits the ticket?",
      "criteria": {
        "billing": "Charges, refunds, invoices",
        "bug": "Software crashes or malfunctions",
        "other": "Anything else"
      }
    },
    "urgency": {
      "type": "score",
      "instructions": "How urgent is the ticket?",
      "criteria": ["not urgent", "somewhat urgent", "urgent", "critical"]
    }
  }
}
```

- Boolean: `"type": "noul"` (NOT `"boolean"`; see Field-name variants). `criteria` omitted.
- Choice: `criteria` is an object `{option: description}`.
- Score: `criteria` is an ordered list, lowest rung first (index = score value).
- `state` accepted as an object (above) and as a message-style array (see Images). A plain string was not tested.

Notes:

- Response headers on 200: `x-generation-id`, `x-provider-name: Inception`, `content-encoding: gzip`. No `x-ratelimit-*` headers were observed. The body `id` equals `x-generation-id`.
- Output is deterministic: the same request on the free and paid models gave identical probabilities.

### Images

**accepted.** A message-style array with an `image_url` content part works, and the model really reads pixels.

Request (base64 elided; the PNG is 200x100, white background, black pixel text "ERROR 500", generated by the script):

```json
{
  "model": "inception/mercury-decide:free",
  "state": [
    {
      "role": "user",
      "content": [
        {"type": "text", "text": "Screenshot of the failing page."},
        {"type": "image_url", "image_url": {"url": "data:image/png;base64,<388 chars>"}}

    }
  ],
  "questions": {
    "shows_error": {"type": "noul", "instructions": "Does the image show an error message?"}
  }

```

Response (HTTP 200):

  "model": "inception/mercury-decide-20260930",

  "id": "gen-dec-1792515036-OTbKazdnnKeWaCDozynG",

Control, because the text above may have biased the answer. The `state` was image-only (no text part), with the question `"Does the image contain the text 'ERROR 500'?"`:

### Free-tier 429 behaviour

**Not triggered.** 40 simultaneous calls (`asyncio.gather`, one `httpx.AsyncClient`) on `inception/mercury-decide:free` all returned HTTP 200 (`{200: 40}`). No 429, so there are no 429 status, header or `Retry-After` values to record. No `x-ratelimit-*` or `retry-after` headers appeared on any 200 response either.

Caveats: the whole run used about 55 free calls within about 90 seconds. A 429 may still occur with sustained volume, other times of day, or higher concurrency (OpenRouter's documented free-model limits are not visible in the response headers). The client must still handle 429, and its exact body shape is unknown; assume the standard `{"error": {"message", "code": 429}}` envelope plus a possible `Retry-After` header.

### Implications for the client

- POST to `https://openrouter.ai/api/v1/systemone` with `{"model", "state", "questions"}`. Map the factory's `boolean` type to the wire type `"noul"`; keep `choice` (criteria = dict) and `score` (criteria = ordered list, lowest rung first).
- Parse by answer `type`: `noul` -> `answer["noul"]` (P(true)); `choice` -> `answer["choice"]` plus `probabilities` and `confidence`; `score` -> float `answer["score"]` (round or threshold it yourself) plus `legend`, `probabilities`, `confidence`. Ignore unknown extra fields.
- Images need no special handling: pass `state` as a message array with `image_url` data-URL parts. Task 15 should take branch B (images accepted). Keep it to `data:` PNG/base64 unless remote URLs are verified.
- Treat any non-200 as `{"error": {"message", "code"}}`. For 400 validation errors `message` is a JSON string, so surface it raw. Retry only on 429 and 5xx, honoring `Retry-After` when present, with exponential backoff. Do not retry 400 or 401.
- Default to `inception/mercury-decide:free` and fall back to `inception/mercury-decide` (identical answers, about $5e-6 per 3-question call) on a 429 or persistent failure. Record `usage` for cost accounting. Reuse one HTTP client for connection pooling, and set a generous timeout (outliers reach about 1.6 s under load).
- Outputs are deterministic for identical input, so identical decisions can be cached safely. Task 6's `client.py` notes should say `noul`, not `boolean`.
